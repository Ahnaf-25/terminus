# Terminus

The last stop is the finals. A railway-ticket study plan for the BUET L4T1 term finals (MME 401, 435, 405, 421 and HUM 405).

**Open it: https://ahnaf-25.github.io/terminus/**

- **Today**: the next two topics as tear-off stubs, your pace to the next checkpoint, and the exam board.
- **Plan**: the whole calendar with checkpoints, exam windows and exams.
- **Courses**: every topic with the work to do (study, solve, practise, note) and each past question that touched it.
- **Cut order**: if you fall behind, which topics to set aside, in order. Core topics are never offered.
- **Undo** after every change, and a progress code to move your ticks between phone and laptop.

Install it from the browser menu (Android and desktop Chrome: Install app; iPhone: Share, then Add to Home Screen). After the first visit it works offline.

## Privacy

There is no account and no server. Your ticks are saved in your own browser only and never leave your device. The plan itself is the same for everyone.
